# Автотесты формы входа ibank (создание пользователя через API)

## Запуск
1. Запустить SUT в тестовом режиме: `java -jar artifacts/app-ibank.jar -P:profile=test`
2. Запустить тесты: `./gradlew test` (в Windows: `gradlew.bat test`)
